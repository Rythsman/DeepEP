🔍 常用命令速查:

【查看网卡速率】
  cat /sys/class/net/eth0/speed
  ethtool eth0 | grep Speed
  
【列出所有网络接口】
  python3 monitor_bandwidth.py -l
  ls /sys/class/net/

【实时监控带宽】
  python3 monitor_bandwidth.py eth0              # 基础模式
  python3 monitor_bandwidth.py eth0 -p -e        # 详细模式
  python3 monitor_bandwidth.py eth0 -u mbps      # 使用 Mbps

【完整系统检测】
  ./quick_check_nic.sh
  python3 check_nic_bandwidth.py

【安装工具】
  sudo ./install_tools.sh

【查看帮助】
  python3 monitor_bandwidth.py -h

💡 重要提示:

1. CX7 网卡支持的最高速率:
   - InfiniBand NDR: 400 Gbps
   - InfiniBand HDR: 200 Gbps
   - Ethernet: 400GbE / 200GbE

2. 如果速率显示为 "Unknown" 或 "-1":
   - 可能是虚拟接口（如 docker0）
   - 可能未连接网线
   - 尝试使用: ethtool eth0

3. 实时监控按 Ctrl+C 停止，会显示累计统计

4. 当前环境检测结果（运行 quick_check_nic.sh 查看）:
   - 发现接口: eth0 (up), docker0 (down)
   - 缺少工具: ethtool, lspci, ibstat 等
   - 建议: 运行 install_tools.sh 安装
